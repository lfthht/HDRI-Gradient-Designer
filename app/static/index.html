Setup for a new Houdini user

      
    
        
  1. Houdini + Redshift on the same computer as this app (Houdini reads the EXR straight from
          output/). The scene uses Redshift's default OCIO config (ACEScg working space,
          view sRGB / ACES 1.0 SDR-video).
    2. 
        
  2. Install FXHoudiniMCP — free, MIT: github.com/healkeiser/fxhoudinimcp. Follow its install guide; it
          adds a Houdini package (Documents/houdiniXX.X/packages/fxhoudinimcp.json) that starts a small
          local web server inside Houdini.
    3. 
        
  3. In that package file check FXHOUDINIMCP_PORT (default 8100), FXHOUDINIMCP_BIND
          (127.0.0.1) and FXHOUDINIMCP_AUTOSTART = 1 so it starts with Houdini.
    4. 
        
  4. Start Houdini and open your scene. Enter the same host / port here and press Test connection
          — it shows the Houdini version and the open .hip file.
    5. 
        
  5. Pick the camera, then Sync from Houdini (Camera view) to match lens and direction, and
          Export + send to dome to put the HDRI on a Redshift dome light in /obj.
    6. 
      

      
Notes: the designer only adds / replaces its own dome node (recreated on every send) and switches other domes
        off, it never deletes them. Redshift's ROP clamps (Max Subsample / Secondary Ray Intensity, default 4)
        clip the physical sun in reflections — raise them on the ROP if needed. Solaris / LOPs scenes aren't
        supported yet (OBJ-level Redshift lights only).

Click exactly on the horizon line inside a clean patch of sky — the column above the click (±30 px median) is sampled up to the top of the frame.
      Sample two gradients from one image: set the Sun side column (warm sky toward the sun), then the Away side column (the other part of the sky) — after the first click it switches automatically.
      Both share the horizon line of the last click. Shift-click moves only the column.
